LLM inference in the browser,
on hand-written WGSL.

zero-tvm is an LLM inference engine written by hand in WGSL and TypeScript. It runs entirely in the browser: weights download once, cache locally, and inference runs on your own GPU.

// Softmax over every expert, then the top-K survivors. One subgroup,
// eight experts per lane: subgroupMax/subgroupAdd reduce with no barrier.
var m : f32 = -3.0e38;
for (var i : u32 = 0u; i < PER; i = i + 1u) {
  let e : u32 = t * PER + i;
  // Lanes past E must lose every max: -inf, not 0 (logits can be negative).
  let v : f32 = select(-3.0e38, logits[lBase + e], e < E);
  pv[i] = v;
  m = max(m, v);
}
let peak : f32 = subgroupMax(m);
