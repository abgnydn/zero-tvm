Why this exists

One readable answer to a compiled stack.

Browser LLM runtimes ship compiler-emitted shader blobs. This repo makes the opposite bet: a forward pass you can read in one sitting, competitive with the compiled stacks on identical weights — and reaching where they haven't shipped: the newest model here is a 35B sparse MoE that no compiler stack offers a build of at all. Every layer is validated against the reference implementation's own modules before it ships, and every performance claim is measured under a written protocol — including the ones we withdrew.
