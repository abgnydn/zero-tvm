LLM inference in the browser,
on hand-written WGSL.

zero-tvm is an LLM inference engine written by hand in WGSL and TypeScript. It runs entirely in the browser: weights download once, cache locally, and inference runs on your own GPU. It is measured against WebLLM and against LM Studio, and the protocol, the raw runs and the withdrawn claims are all in BENCH.md.

// RMSNORM — normalize hidden state. output[i] = (input[i] / rms) * gamma[i]
@compute @workgroup_size(64, 1, 1)
fn rms_norm(...) {
// Phase 1: sum of squares in f32
var sum_sq : f32 = 0.0;
for (var i = 0; i < D / 64; i++) {
let val = f32(input_buf[base + tid * (D / 64) + i]);
sum_sq = sum_sq + val * val;
}
// tree-reduce across 64 threads, then:
let rms_inv = 1.0 / sqrt(red_buf[0] / f32(D) + RMS_EPS);
output_buf[base + idx] = f16(val * rms_inv * f32(gamma[idx]));
}

About

What this is

Zero-TVM is an LLM inference engine for the browser. The standard stacks compile their shaders (WebLLM/TVM emits 85 autotuned kernels behind a WASM scheduler); this engine is written by hand instead.

  • 10 kernel roles — 42 WGSL files plus a small generator
  • No runtime dependencies: no WebLLM, no TVM, no ONNX, no WASM
  • int4 / int3 quantized weights, loaded by byte range, cached in OPFS
  • Paged KV cache, gated DeltaNet, sparse-MoE routing — all in plain WGSL
  • Layers validated against reference implementations (mlx_lm's own modules)
  • Benchmarked against WebLLM on identical weights; protocol and all numbers in BENCH.md
  • MIT
