Not a same-bytes comparison. transformers.js reads ONNX q4f16 (MatMulNBits 4-bit blocks, fp16 activations); Zero-TVM and the WebLLM baseline read MLC q4f16_1. Same bit width and the same activation dtype, but a different block layout and different rounding — the files are not byte-identical. Every number on this page is therefore a runtime + quantization result, not the clean runtime-only A/B that webllm-bench is. The confound is smaller than the wllama page's GGUF Q4_K_M, but it is not zero.

?ttft=1 runs the TTFT-vs-prompt-length sweep instead of the standard throughput protocol — the measurement behind huggingface/transformers.js#1599. ?device=wasm is the CPU control run.
